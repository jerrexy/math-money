# Blender → Roblox asset pipeline

Every model in Math Money is generated by the Python scripts in `tools/blender`.
They run inside Blender (4.1+), and `assets/blender/MathMoney.blend` is their saved
output. This folder holds what's needed to get those models into the game.

## 1. Build and export (Blender)

From Blender's Python console (or the Blender MCP):

```python
import sys; sys.path.insert(0, r"<repo>/tools/blender")
import mm_lib, build_apparatus, build_valuables, build_plants, build_wearables, build_props
build_apparatus.build(); build_apparatus.build_chain_link(); build_valuables.build()
build_plants.build(); build_wearables.build(); build_props.build()
mm_lib.export_fbx_bundle("MathMoney_All", [...prefab names...])
```

Each `build()` writes `build/prefabs/<Prefab>.json`, which records where every
part sits, its material and colour, collision, and the marker CFrames such as
the chain path and camera shot. `export_fbx_bundle` writes
`assets/meshes/MathMoney_All.fbx`, naming each mesh node `<Prefab>__<Part>`.

**Conventions.** 1 Blender unit equals 1 stud, Z is up, and the front of every
model faces −Y. The exporter converts that to Roblox axes, so the front ends up
facing −Z.

## 2. Import (Studio)

Use **Home → Import 3D**, pick `MathMoney_All.fbx` and click **Import**. Keep the
default settings, which import vertex colours. This uploads the meshes to your
account.

## 3. Assemble (Studio)

Start the dev server with `python tools/pipeline/dev_server.py`, temporarily
turn on `HttpService.HttpEnabled`, then run this in the command bar:

```lua
loadstring(game:GetService("HttpService"):GetAsync(
    "http://127.0.0.1:8765/tools/pipeline/assemble_all.luau"))().run()
```

This rebuilds every prefab from the imported MeshParts exactly as laid out in
the JSON manifests. It writes the `.rbxm` files into `assets/models/...`, which
Rojo then syncs into the game. It also records mesh ids in
`assets/meshes/asset_ids.json`.

## Files

| File | What it does |
|---|---|
| `dev_server.py` | Local HTTP bridge so Studio can read build output and write `.rbxm` back into the repo. Binds to 127.0.0.1 only. |
| `assemble_import.luau` | Turns imported MeshParts into prefab Models. |
| `assemble_all.luau` | The full output mapping (prefab → `.rbxm` file). |
| `import_prefab.luau` | Previews a prefab from raw mesh data without uploading anything, builds a box-shaped placeholder for testing, or rebuilds a prefab from the recorded mesh ids. |

Why the 3D Importer? Uploading meshes from a script needs
`AssetService:CreateAssetAsync`. Roblox reported that API as "not available yet",
even from a local plugin, when this project was set up. If that changes, the
JSON meshes in `build/meshes` can be uploaded directly instead.
